## How it runs
Command Centre → "Temporary passwords for the seated leaders (HQ master
lists)" → confirm. The app sends the list to admin-users action
bulk_reset_list, which for each person: finds the WDOS login by email
(profiles.email, case-insensitive), sets a fresh 12-character temporary
password, reads the current seat, and notes whether the person had signed
in before. Anyone whose email has no WDOS login is reported at the bottom
of the sheet as "not found", never created. Sheet: Nigeria by state
(SC then ASC), then Africa by country (CR then DCR), shown once.

The v80.8 directory-wide button was replaced by this one so the wrong
people cannot be reset by accident.
